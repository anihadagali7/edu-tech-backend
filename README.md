# EduTech Backend

The API for EduTech, an adaptive quiz platform. It serves topics and quizzes whose difficulty follows the learner's answers, uses Claude to write questions, and runs a tutor chatbot (Study Buddy).

- **Stack:** Python 3.11, FastAPI, SQLAlchemy 2 (async) + Alembic, Postgres, Clerk JWT auth, Server-Sent Events, Claude (`anthropic` SDK)
- **Hosted on:** Heroku (one web dyno) + Neon Postgres. The UI ([`edu-tech-ui`](https://github.com/anihadagali7/edu-tech-ui)) is on Vercel.

> **Revival in progress (Oct 2026).** The code still calls OpenAI through LangChain, and it needs a few fixes before it runs on Heroku and Neon. Work through [docs/revival-plan.md](docs/revival-plan.md) in order.

## Run locally

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev
# create .env (see docs/deployment.md#api-env-vars); point DATABASE_URL at a Neon dev branch
alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

- Interactive API reference: http://localhost:8000/docs (generated by FastAPI from the code, so it is always current)
- Health check: `GET /health`
- Process queued LLM jobs by hand: `python run_worker.py`

## Tests

pytest            # tests/ only; the test_*.py files at the repo root are old debug scripts

## Layout

```
app/
├── main.py                 app factory: CORS, request IDs, error envelope
├── api/routes.py           mounts every router (start reading here)
├── auth/                   Clerk JWT check, role guard
├── db/                     models, repositories, Alembic migrations
├── features/
│   ├── topics.py           topics, search, topic requests, admin topic CRUD
│   ├── quizzes/            adaptive engine (service.py) + live quiz stream (sse.py)
│   ├── llm/                job endpoints, worker, LLM provider
│   ├── study_buddy/        tutor chatbot (flag: ENABLE_STUDY_BUDDY)
│   ├── learning_content/   generated study notes (flag: ENABLE_LEARNING_MATERIALS)
│   ├── admin/reporting.py  users, events, exports
│   └── profile.py
└── utils/                  errors, logging, ids
prompts/                    prompt text and templates
scripts/                    ops helpers (inspect jobs, retry a failed job, ...)
tests/                      pytest suite
```
